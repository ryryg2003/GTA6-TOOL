# Research sources

Ranked by trust. Start here, then use web search to go wider. Trust level decides confidence:
**official** alone → `confirmed`. **reputable** alone → `likely` (two reputable sources agreeing → `confirmed`).
**community** alone → `unverified` (community + a reputable source agreeing → `likely`).

| Source | Trust | Good for |
|---|---|---|
| rockstargames.com/VI, Rockstar Newswire (rockstargames.com/newswire) | official | features, vehicles/weapons shown officially, updates/patches |
| PlayStation / Xbox trophy & achievement lists (store pages, PSN trophy lists) | official | trophies |
| IGN guides (ign.com) | reputable | missions, collectibles, maps |
| GameSpot, PCGamesN, GamesRadar, Eurogamer, Polygon, GameRant | reputable | guides, walkthroughs, collectible locations |
| GTA Wiki on Fandom (gta.fandom.com) | reputable | weapon/vehicle stats, mission lists |
| PowerPyx, PSNProfiles guides | reputable | trophies, missables, collectibles |
| r/GTA6 and r/GTA on Reddit | community | newly found secrets, safe codes, early stats |
| GameFAQs boards and guides | community | stats, walkthroughs |
| YouTube video descriptions/titles (not the videos) | community | collectible locations with timestamps |

Rules: follow robots.txt, skip pages behind a login or paywall, keep it to roughly one request per second
per site, and never copy article text: write the fact in your own words and link the page.
